03 — Typography

Type system

Real fonts load in Remotion (this page previews with system stand-ins — artifact pages can't fetch webfonts).

Lane A pairing
Fraunces — model names
IBM Plex Mono — specs & dealer tag

Model name: 84–96px eq., wt 600, tracking +0.5px, never all-caps. Spec line: 30px eq., tracking +3px, 78% opacity. Dealer tag appears only on end card.

Lane B pairing
Archivo Black — model names
Space Mono — specs & dealer tag

Model name: 96–110px eq., wt 900, tracking −1px, ALL CAPS, snaps from tracking +8px on entry. Spec line: 28px eq., accent color, steps() flicker on entry. Tag bottom-left, persistent at 55% opacity.

04 — Composition & framing

Every cut intentional

Hero

Bike centered for impact; type in upper negative space; never covers motor/suspension/wheel.

Macro detail

Offset to a thirds line; brake / throttle / swingarm fills 60%+; type reacts to the empty third.

Action

Diagonal energy, motion blur kept; horizon tilted 5–8°; slideshows push-in 4–6% linear — never random Ken Burns.

05 — Master template

Reel skeleton (12–15s)

INTRO0–1.5s · kinetic name
3–4 CUTShero → macro → action · on the kick
SPECone factual line
END CARDlogo + Kissimmee, FL

Lane B cuts land every 2 beats (126 BPM → ~0.95s ≈ 29 frames); one speed-ramp 100→40→100% mid-reel; one 6-frame freeze on the hero. Lane A cuts every 2 beats (88 BPM → ~1.36s ≈ 41 frames), single bloom transition max. Arctic Leopard (#1) is the reference render — every other bike inherits this skeleton with its own palette + accent.
