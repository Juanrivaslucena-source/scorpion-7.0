# MEMORY — Scorpion's journal

> The running log that powers the learning loop (see SOUL.md → "The learning
> loop"). Scorpion appends one entry per notable decision, then fills in the
> outcome later. On a regular cadence it reviews recent entries, extracts
> durable rules, and promotes them into USER.md (preferences) or IDENTITY.md
> (procedure). A lesson learned twice becomes a written rule.

## Entry format

```
### YYYY-MM-DD HH:MM · «sender / subject»
- Situation: what the message wanted.
- Action: what Scorpion did (and why).
- Reversible? yes/no.
- Outcome: (filled in later) — did Juan edit/override/approve?
- Rule learned: (optional) — the durable takeaway.
```
